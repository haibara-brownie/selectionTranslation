### 本机装的是什么（重要）

```
/usr/bin/seltrans   →  0.3.0 Tauri 版，**pacman 包**
```

2026-08-21 换成了正经的 Arch 包（`packaging/arch/PKGBUILD`，`makepkg -si`）。
之前那个 `~/.local/bin/seltrans` 是 `install.sh` 直接拷进去的、pacman 不认，已删除。

```bash
pacman -Qi seltrans      # 看信息
pacman -Ql seltrans      # 看装了哪些文件
pacman -R  seltrans      # 卸载
```

**没走 debtap 转换 deb**：debtap 自己的说明第一句就是「不要用它转换那些
已经在官方仓库、或者能从 AUR 构建的包」，我们正是这种情况；而且它把 Debian
包名启发式映射成 Arch 名，我们 deb 里声明的 `libwebkit2gtk-4.1-0` / `libgtk-3-0`
转出来八成对不上。直接 makepkg 出来的是同一种 pacman 包，但依赖名是准的。

旧的 GTK 0.1.0 备份在 `/tmp/seltrans-gtk-0.1.0.bak`（重启就没了），
仓库里 `v0.1.0-gtk` tag 是可靠的退路。

## 验证手法（省得重新摸索）

工具在 `docs/workbench/tools/`，README 里有详细说明。要点：

- `wl-copy --primary "..."` 造「划过词」的状态，驱动整条快捷键通路，不碰剪贴板
- 动画要**录像抽帧**验：`wf-recorder -r 60` + `ffmpeg crop/fps/tile`，截图抓不到 120ms 的动画
- 发按键前**必须先确认焦点**（`niri msg -j windows` 找 `is_focused`）；
  一律走 `tools/safekey.sh`（带 trap，四种退出都保证抬起修饰键）
- **不要用 `pkill -f`** —— 会匹配到 Bash 工具自己的 shell，退出码 144
- 设置窗口里数 Tab：标签 4 个 + ✕ 共 5 下，**第 6 下才进内容区**
  （数错会点到 ✕ 把窗口关掉，我踩了两次）
