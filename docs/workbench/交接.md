### 本机装的是什么（重要）

```
~/.local/bin/seltrans   →  0.3.0 Tauri 版
```

**是 `install.sh` 用 `install -m755` 直接拷进去的，pacman 完全不知道它的存在**
（`pacman -Qo` 查不到属主）。所以没有版本记录、没法 `pacman -R` 卸载、
不参与系统更新。

旧的 GTK 0.1.0 备份在 `/tmp/seltrans-gtk-0.1.0.bak`（重启就没了），
仓库里 `v0.1.0-gtk` tag 是可靠的退路。

## 下一件事：打成真正的 Arch 包（进行中，未开始改）

用户提出「该打成 arch 可用的包安装」——方向对，但**不是 deb**（那是 Debian/Ubuntu 的）。
Arch 用 pacman 包（`.pkg.tar.zst`），靠 `PKGBUILD` 构建。

**`packaging/aur/PKGBUILD` 现在是过期的**，还停在 GTK 版：

```
pkgver=0.1.0                                    # 应为 0.3.0
depends=('gtk4' 'libadwaita>=1.7' ...)          # 应为 webkit2gtk-4.1 gtk3 libayatana-appindicator
makedepends=('cargo')                           # 少 pnpm / nodejs
build(): cargo build --frozen --release         # ❌ 这样编出来的跑不起来，见下
pkgdesc 里还写着「GTK4 / libadwaita」
```

### 改的时候必踩的三个坑

1. **`cargo build --release` 编出来的 Tauri 二进制跑不起来** ——
   窗口一片空白、左上角 `Connection refused`。Tauri 靠 `tauri` 依赖有没有开
   `custom-protocol` 特性判断 dev/生产（它 build.rs 里就一行
   `let dev = !has_feature("custom-protocol")`），只有 `tauri build` 会加，
   跟 `--release` 无关。PKGBUILD 里要走 `pnpm tauri build --no-bundle`
   或手动加 `--features tauri/custom-protocol`。
2. **AUR 构建期不许联网**，`pnpm install` 得靠预下载的 tarball 喂
   （`packaging/aur/README.md` 里记过这条）。本地 `makepkg` 不受此限。
3. **`options=('!lto')` 不能去掉** —— makepkg 默认加 `-flto=auto`，会把
   `aws-lc-sys`（rustls 的加密后端）的 C 目标文件编成 LLVM bitcode，
   链接时一堆 `undefined symbol: aws_lc_0_44_0_*`。

装好之后记得把 `~/.local/bin/seltrans` 删掉，否则 PATH 里两个同名的会打架。

## 验证手法（省得重新摸索）

工具在 `docs/workbench/tools/`，README 里有详细说明。要点：

- `wl-copy --primary "..."` 造「划过词」的状态，驱动整条快捷键通路，不碰剪贴板
- 动画要**录像抽帧**验：`wf-recorder -r 60` + `ffmpeg crop/fps/tile`，截图抓不到 120ms 的动画
- 发按键前**必须先确认焦点**（`niri msg -j windows` 找 `is_focused`）；
  一律走 `tools/safekey.sh`（带 trap，四种退出都保证抬起修饰键）
- **不要用 `pkill -f`** —— 会匹配到 Bash 工具自己的 shell，退出码 144
- 设置窗口里数 Tab：标签 4 个 + ✕ 共 5 下，**第 6 下才进内容区**
  （数错会点到 ✕ 把窗口关掉，我踩了两次）
