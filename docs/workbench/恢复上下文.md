# 压缩上下文之后怎么让我快速回到状态

## 压缩指令

在对话框里敲：

```
/compact 保留：seltrans 项目当前状态、Arch 包安装进度、Windows 待验清单、
docs/workbench/交接.md 的内容要点。丢弃：所有截图分析、逐条回归验证的过程、
CI 日志排查细节、已完成票的实现讨论。
```

## 压缩之后发这句

```
读 docs/workbench/交接.md 和 progress.log.md 末尾 20 行，然后告诉我现在该做什么
```

这一句就够了 —— 交接文档里有现状、下一件事、没验的东西、以及这台机器上被动过的
系统状态。我读完会自己对齐。

## 为什么这样就够

工作台是**入库**的（`docs/workbench/`），跟着仓库走，压缩上下文不会丢。
`交接.md` 里刻意写了这几样，就是为了扛住上下文丢失：

- 一句话现状 + 三平台各自能不能用
- **下一件事**，以及做它会踩的坑
- 已知但没验的清单
- 这台机器上**被改过的系统状态**（哪些动了、哪些没动）
- 攒下的验证手法（省得重新摸索）

规矩见 `.claude/commands/LOGGING.md`：不确定进度时先读日志末尾，
**禁止**为了"确认做到哪了"去重读规格和源码。
