# workbench — 开发过程台账

作者在多台机器（Arch 工作站 / Mac）之间接续开发本项目，这里存放过程状态：规格、票、进度日志、评审产物。**随仓库同步，所以是公开的。**

- **[交接.md](交接.md) — 接手先读这份**（现状、下一件事、没验的、被动过的系统状态）
- `progress.log.md` — 滚动进度日志（修 bug / 轻量工作）
- `tools/` — 验证界面行为用的小脚本，两台机器共用
- `<feature>/` — 中度及以上的功能各自建目录，内含 `spec.md`、`tickets/`、`progress.log.md`
- `reviews/` — 评审产物

对使用者没有意义，读代码请看仓库根的 [README.md](../../README.md)。

**纪律**：凭据、API key、内网地址、端口一律不写进这里——本目录是公开的。
