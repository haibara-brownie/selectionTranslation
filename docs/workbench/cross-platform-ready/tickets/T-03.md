流式文字现在是逐段直接贴上去。要有渐现/光标感，而不是整块跳出来。

**注意**：别为了动效牺牲首字延迟——划词翻译的全部价值就在于快。
动画只能加在「已经到达的字」上，不能延后显示。

**验收**：真机上看得出逐字/逐段的渐进，且首字出现时间不比现在慢。

---

## 已完成（2026-08-20）

每个流式分片单独包一层 `<span class="chunk">` 才能逐段渐现；`textContent` 读出来仍是完整
译文，复制那条路不受影响。

**起始透明度刻意不是 0**（用的 0.15）。划词翻译最忌讳首字变慢，从 0 起等于让第一个 token
晚一百多毫秒才看得见——票里「首字出现时间不比现在慢」这条就是冲这个来的。

顺带修了一处叠加：光标原本是 `.output.streaming::after`，只要在流式态就画，于是等首个
token 的那几秒里**光标和骨架屏一起出现**，两个占位叠着看着像出错。改成
`.output.streaming.typing::after`，`.typing` 由第一个分片打上。

**验证状态：部分。** 译文渲染正确（截图确认），但 120ms 的分片渐现没在抽帧里分辨出来。
