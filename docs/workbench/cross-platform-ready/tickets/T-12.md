本轮（2026-08-20，Mac 侧）改了大量**三平台共用**的代码：`windows.rs`、`main.rs`、
整个前端。mac 上逐条验过了，Linux 一次都没跑过。**这张票是本 feature 的最后一关。**

## 先跑起来

Arch 上和 Mac 不同：**能编全部三个 package**，不需要 `--exclude seltrans`。

```bash
git pull
pnpm install                      # 前端依赖没变，但保险
cargo fmt --all --check
cargo clippy --workspace --all-targets -- -D warnings
cargo test --workspace
pnpm build
cargo build --release             # GTK 版和 Tauri 版都会编
```

然后跑 Tauri 版（**不要覆盖你日常在用的 `~/.local/bin/seltrans`**，那是 GTK 版）：

```bash
./target/release/seltrans-tauri tray &
```

## 必须回归的（按重要性排，每条都注明为什么）

### 1. 常驻后**第一次**按快捷键就要出译文

修复提交 `e44c260`。`open_popup` 新建窗口那条路上原本没把取到的文本写进 `Launch` 槽位，
表现是常驻起来后第一次触发开出一个**空弹窗**，第二次才正常。

**Linux 上这是日常主路径**（合成器每次按键都 spawn 新进程 → single-instance 递给常驻实例
→ 新建或复用窗口）。mac 上验过了，Linux 必须再验一遍。

> 验法：`pkill seltrans-tauri`，重新 `tray &`，选中一段文字，**按第一次**就该出译文。

### 2. 一次触发只取一次词

修复提交 `058a454`。原先新进程在 `tauri::Builder` 之前取一次、常驻实例回调里又取一次。
**Linux 是重灾区**：合成器每次按键都 spawn 新进程，所以每次都双取；一旦掉进 Ctrl+C
兜底，就是两轮「抬修饰键 → 模拟复制 → 等剪贴板 → 还原」，用户剪贴板被改写还原两遍。

> 验法：`tail -f` 日志，按一次快捷键，**「开始取词」只该出现一次**。
> 特别要试一个不支持主选区的应用（某些 Electron），确认「模拟 Ctrl+C」也只出现一次。

### 3. 关掉设置窗口，托盘不能跟着没

修复提交 `4083345`。Tauri 默认「所有窗口都关了就退出」；弹窗靠 `prevent_close` 绕开了，
设置窗口是真销毁的，于是按一次 Esc 整个程序退出——托盘图标消失、快捷键失效。

> 验法：`tray &` 之后打开设置页，按 Esc 关掉，**托盘图标还在、快捷键还能用**。

### 4. 弹窗位置仍归 niri 管

新加的 `place_top_right()` 是 `#[cfg(not(target_os = "linux"))]`，理论上 Linux 不编译它。
但要确认弹窗**还是老样子出现在右上角**，没有被应用自己摆位干扰。

### 5. 自绘下拉在 WebKitGTK 上的表现

**这是本轮改动面最大的一块**，原来用的是原生 `<select>`。四个点都要看：

- 顶栏「翻译风格」和底栏「模型」都能展开，**浮层不被裁**（浮层现在挂在 `document.body`
  上用 `position: fixed`，就是为了逃开祖先的 `overflow: hidden`）
- 底部那个下拉空间不够时**向上翻**
- 设置页四个下拉（目标语言/默认提示词/取词方式/配色）以及字体那三个搜索框
- 键盘：Tab 聚焦、空格展开、↑↓ 移动、Enter 选中、Esc 只收下拉不关窗

### 6. 动效在 WebKitGTK 上不卡

弹窗进场/退场、译文流式渐现、骨架屏、切风格时的交叉淡出。
mac 上是 WKWebView，Linux 是 WebKitGTK，同一套 CSS 未必一样顺。
**尤其看首字延迟有没有变慢**——分片渐现的起始透明度刻意设成 0.15 就是为了这个。

### 7. 新的小尺寸托盘图标（**Linux 专属，mac 上看不到**）

新增 `data/tray-small.svg`，ksni 在 22/32 两档用它，48/64 仍用应用图标。
这份图**只有 Linux 会用**，Mac 侧只能靠单测（`cargo test -p seltrans-tauri` 里的
`托盘小尺寸图在_22px_下箭头仍是可辨的镂空`）间接保证，**观感必须你在 niri 面板上看**。

> 看不清就调 `data/tray-small.svg`，改完 `cargo test -p seltrans-tauri` 会告诉你有没有
> 把箭头调没。

### 8. 快捷键：Linux 分支不该出现录制控件

`Mod+Shift+T` / `Mod+Alt+T` 应完全不受影响（本轮只改了非 Linux 分支的默认值）。
设置页的「快捷键」分组在 Linux 上**应当列出 niri 提供的按键 + 说明为什么改不了**，
而不是显示 mac/Windows 那两个录制按钮。

### 9. 「关于」页的依赖自检

Linux 分支应仍显示 wl-clipboard / ydotool / niri 规则的状态。
