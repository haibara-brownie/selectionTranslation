本轮改动碰了 `windows.rs` / `main.rs` / 整个前端，这些都是三平台共用的。
Linux 上必须回归，重点：

- 常驻后**第一次**按快捷键就该出译文（`e44c260` 修的空弹窗，Linux 上是日常主路径）
- 关掉设置窗口后托盘还在（`4083345`）
- 弹窗仍由 niri 的 window-rule 摆到右上角，没被 `place_top_right` 抢走
  （那段是 `#[cfg(not(target_os = "linux"))]`，理论上不该生效，但要确认）
- 自绘下拉在 WebKitGTK 上的表现：浮层不被裁、键盘导航正常、动画不卡
- `Mod+Shift+T` / `Mod+Alt+T` 未受影响（本轮只改了非 Linux 分支的默认键）
