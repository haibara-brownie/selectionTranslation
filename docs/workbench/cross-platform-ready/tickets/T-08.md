`tray.rs` 里 `icon_as_template(false)`，注释已说明原因：现有图标是彩色的、alpha 几乎是满的，
切成模板会变成两坨看不出内容的黑块。需要另配一张单色图 `icons/tray-mono.png`，
再把非 Linux 分支改成 `icon_as_template(true)`。

深色菜单栏里彩色图标很突兀，这是 mac 上最后的打磨项。

**验收**：mac 真机截图，浅色和深色菜单栏下图标都清晰、跟系统其他图标观感一致。

## 已完成（2026-08-20）

没有按票里设想的「另配一张 tray-mono.png」，而是**新增单色 SVG + 现场光栅化**：
`data/tray-mono.svg` 里把字形挖成洞（mask 涂黑），mac 上用 resvg 光栅化成 RGBA 喂给
Tauri 的 `Image::new_owned`，`icon_as_template(true)`。

理由：几何数据已经在 SVG 里了，再烤一张 PNG 进仓库就是两个事实源，改图标时必然漏改
一个。Linux 那边（ksni）本来就是现场光栅化的，用的同一套 resvg，只是终点从 SNI 的
ARGB 换成 Tauri 的 RGBA。为此把 resvg 从 Linux 专属改成 linux+macos 共用。

单色化还有一处不能省：两只气泡在彩色版里靠色相区分，单色下会糊成一块。前面那只先挖一圈
比自己大 1.6 的缝再画本体，两只之间就有了分隔线。

### 验证状态

- **光栅化：已验证。** 新增单测 `单色托盘图标要有内容也要有镂空`，同时卡住两头：
  不透明像素太少（画成空白）和透明像素太少（mask 没生效 → 菜单栏上一坨黑块）。
  这两种失败在菜单栏上都很难看出来，只会表现成"图标不见了"或"图标很怪"。
- **外观：已验证。** 把 RGBA 导出来分别叠在浅色和深色底上看过：两只气泡有清晰分隔缝，
  「A」「文」镂空可读，深色底上自动反白。
- **菜单栏实景：没验成。** 这台机器的菜单栏被 iStat 那排读数占满，macOS 把我们的图标
  挤到了屏幕外（AX 报的位置是 -3722，典型的"被隐藏"坐标）。**换一台菜单栏不拥挤的
  机器、或临时关掉几个菜单栏应用才能看到实景。**
