默认键写死就一定会撞上某些用户的既有绑定（Bob / Raycast / 输入法等）。
撞上时 `register` 返回 Err、程序照常跑，但**用户没有任何办法改**。

需要：config 加字段、设置界面加录制控件、改完重新注册、撞车时给出可见反馈。

Linux 分支不适用——那边快捷键归合成器，改 `~/.config/niri/selectiontranslation.kdl`。
设置界面在 Linux 上应当说明这一点而不是给一个改不动的控件。

**验收**：mac/Windows 上能改键并立即生效；改成已被占用的组合时界面明确报错。
